# gitdrop — self-hosted file exchange

Один Python-файл, никаких баз данных. Drag & drop в браузере, скачивай с любого компа.

## Быстрый деплой на VPS

Скрипт сам поставит Python/Flask, создаст systemd-сервис и откроет порт.
После запуска покажет URL и токен доступа.

## Автоудаление

Файлы и сообщения чата удаляются автоматически через 8 часов после загрузки
(проверка раз в минуту). Срок меняется флагом `--ttl-hours N` или
переменной окружения `GITDROP_TTL_HOURS`.
